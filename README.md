# Novel EPUB Telegram Bot

Novel link -> EPUB (Telegram bot). Sirf Python standard library.

## Render par deploy
1. Ye repo GitHub par push karo (token kabhi file me mat likhna).
2. Render -> New -> Web Service -> repo chuno.
3. Build: `pip install -r requirements.txt`  |  Start: `python bot.py 11`
4. Environment variables: `BOT_TOKEN`, `ADMIN_ID`
5. Deploy dabao.

Version badalna ho: Start command me `python bot.py 15`.
